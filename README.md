## Featured Projects

### 🎓 Student Job Platform
A full-stack platform designed to help students discover and manage internship and job opportunities.

**Tech:** React · Flutter · Node.js · Express · MongoDB

### 🏠 HostelHub
A smart hostel management system designed to simplify hostel-related services and communication.

**Tech:** React · Django · Python · MySQL · Tailwind CSS

### 🛒 AI-Powered Shopping Assistant
A generative AI and RAG-based assistant designed to help users discover and explore products more intelligently.

**Tech:** Python · LangChain · OpenAI · ChromaDB · Flask

### 📧 Mail Automation Agent
An AI-powered workflow for organizing, summarizing, and automating email-related tasks.

**Tech:** Python · LangGraph · OpenAI · Gmail API

### 🔎 Automated Product Search
A web automation and scraping system for searching and collecting product information across platforms.

**Tech:** Python · Selenium · Playwright · FastAPI · PyTest

### 🤖 Military Surveillance Robot
A multi-sensor robotic platform combining computer vision, thermal imaging, GPS, wireless communication, and edge computing.

**Tech:** ROS · C++ · Python · OpenCV · PyTorch · LoRa
